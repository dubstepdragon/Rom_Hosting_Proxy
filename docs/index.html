SNES ROM Link Builder

Turn a direct ROM link into an image URL for the VRChat emulator's VRCImageDownloader. When the URL loads, the proxy downloads the ROM from its original host and converts it on the fly. This site does not store or host any ROMs.

1. ROM link

It must be the file itself, not a download page. The proxy does not scrape download sites.

No place to host your own ROM archives?
Open archive.org/download/gameplay-snes,
1. Find a game you want
2. click view contents
3. Right click a version and copy its link address
4. paste it here.
Feel free to also look for any other files on archive.org that are a zip of a rom or an .smc file. You can also host your own files as well.

2. Image URL for VRCImageDownloader

Games that need enhancement chips (SuperFX, SA-1, DSP-1, Cx4, S-DD1, SPC7110) and ExHiROM cartridges are rejected. Players need Allow Untrusted URLs turned on for image links outside VRChat's trusted list, which includes the proxy's domain.
